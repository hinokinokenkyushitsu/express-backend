# 后端国际化（i18n）改造说明

## 设计思路

**根据请求 Header `Accept-Language` 动态切换中英文响应消息**。
前端在 axios 请求拦截器里设置该 Header，后端通过 `AcceptHeaderLocaleResolver` 自动识别。

支持语言：`zh-CN`（简体中文）、`en`（英文）。Header 缺失或不支持时默认英文。

## 关键实现

### 1. 资源文件

| 文件 | 用途 |
|------|------|
| `messages_zh_CN.properties` | 业务异常的中文消息 |
| `messages_en.properties` | 业务异常的英文消息 |
| `messages.properties` | 兜底（英文） |
| `ValidationMessages_zh_CN.properties` | 表单校验中文 |
| `ValidationMessages_en.properties` | 表单校验英文 |
| `ValidationMessages.properties` | 兜底（英文） |

### 2. 配置 (`I18nConfig`)

- `MessageSource`：加载上述资源文件
- `LocaleResolver`：读取 `Accept-Language`
- `LocalValidatorFactoryBean`：让 Bean Validation 注解的 `message="{xxx.key}"` 也接入 MessageSource

### 3. 业务代码模式

**抛业务异常时只传 message key，不传中文字符串：**

```java
// ❌ 旧写法（硬编码中文）
throw BusinessException.conflict("该订单已被抢走啦");

// ✅ 新写法（i18n key）
throw BusinessException.conflict("order.grab.taken");
```

**带占位符参数的消息：**

```java
String oldName = i18n.t("order.status." + oldStatus);
String newName = i18n.t("order.status." + newStatus);
throw new BusinessException(400, "order.status.illegal.transition",
        oldName, newName);
```

对应资源文件中的占位符 `{0}`、`{1}`：
```properties
order.status.illegal.transition=非法的状态流转：{0} → {1}
order.status.illegal.transition=Illegal status transition: {0} -> {1}
```

**DTO 校验注解：**

```java
@NotBlank(message = "{validation.phone.notBlank}")
@Pattern(regexp = "...", message = "{validation.phone.format}")
private String phone;
```

## 流程示意

```
前端                          后端
 │                             │
 │ POST /api/order/123/grab    │
 │ Accept-Language: zh-CN      │
 ├─────────────────────────────>
 │                             │ AcceptHeaderLocaleResolver
 │                             │   → Locale.SIMPLIFIED_CHINESE
 │                             │ LocaleContextHolder.set(zh_CN)
 │                             │
 │                             │ Service: throw BusinessException("order.grab.taken")
 │                             │
 │                             │ GlobalExceptionHandler:
 │                             │   i18n.t("order.grab.taken")
 │                             │   → 查 messages_zh_CN.properties
 │                             │   → "该订单已被抢走啦"
 │                             │
 │ 409 {code:409,             │
 │      msg:"该订单已被抢走啦"} │
 <─────────────────────────────┤
```

## 测试

启动后用 curl 验证：

```bash
# 中文
curl -H "Accept-Language: zh-CN" http://localhost:8080/api/order/9999/grab

# 英文
curl -H "Accept-Language: en"    http://localhost:8080/api/order/9999/grab
```

## 添加新消息时

1. 在 `messages_zh_CN.properties` 添加：`my.new.message=中文文本`
2. 在 `messages_en.properties` 添加：`my.new.message=English text`
3. 在 `messages.properties` 添加（fallback）：`my.new.message=English text`
4. 业务代码使用：`throw new BusinessException(400, "my.new.message")`
